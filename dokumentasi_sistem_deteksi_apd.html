Sistem Deteksi Penggunaan APD

Deteksi helm dan rompi keselamatan menggunakan YOLO, pencatatan hasil deteksi, dan pengelompokan pola penggunaan APD dengan K-Means.

YOLOv8m YOLOv11m YOLOv26m K-Means CRISP-DM
🦺

▤ Deskripsi Proyek

Proyek skripsi ini berfokus pada deteksi penggunaan helm dan rompi keselamatan menggunakan teknologi computer vision dan deep learning.

Penelitian membandingkan YOLOv8m, YOLOv11m, dan YOLOv26m serta menggunakan K-Means Clustering untuk mengelompokkan kombinasi penggunaan APD.

Pengujian dilakukan dalam skenario simulasi dengan subjek yang berperan sebagai pekerja. Sistem menampilkan hasil deteksi, mendukung pencatatan absensi, dan menyimpan dokumentasi visual.

Metodologi penelitian: Business Understanding → Data Understanding → Data Preparation → Modeling → Evaluation → Deployment.

⇢ Alur Kerja Sistem

01 / INPUT 📷 Pengambilan citra

Kamera atau webcam mengambil citra/video dalam skenario simulasi.

02 / DETECT ◎ Deteksi objek

Model YOLO mendeteksi objek berdasarkan lima kelas yang dilatih.

03 / VALIDATE ✓ Validasi APD

Valid jika helm dan rompi terdeteksi; selain itu Tidak Valid.

04 / RECORD ▤ Pencatatan hasil

Hasil digunakan untuk mendukung absensi CSV dan rekap Excel.

05 / EVIDENCE ▧ Dokumentasi

Hasil deteksi dengan bounding box dan label kelas disimpan.

06 / CLUSTER ⦿ K-Means

Data dikelompokkan berdasarkan kombinasi penggunaan helm dan rompi.

07 / EVALUATE ▥ Evaluasi model

Ketiga model dibandingkan dengan metrik evaluasi deteksi objek.

08 / OUTPUT ▣ Hasil sistem

Tampilan deteksi, rekap kehadiran, dokumentasi, dan hasil clustering.
